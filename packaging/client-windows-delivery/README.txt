1cat Tunnel Windows Client

This folder is ready to hand to a customer.

Files:
- 1cat Tunnel Client.exe
- Start 1cat Tunnel Client.bat
- Start 1cat Tunnel Client.ps1
- client-windows.json

How to use:
1. Double-click "Start 1cat Tunnel Client.bat"
2. If the config is still a template, paste the node-specific bootstrap token from the server console
3. Follow the first-start wizard

Notes:
- No Go installation is required on the customer machine
- Logs are written to tunnel-client.log in this same folder
- The customer machine only needs outbound access to the server control address
