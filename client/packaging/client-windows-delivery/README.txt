1CatTunnel Windows 通用客户端 0.5.2-security
==================================

双击 Start 1cat Tunnel Client.bat，保持运行窗口打开。
打开启动窗口显示的专用登录链接完成配置。链接请勿分享，重启后失效。
也可执行：.\"1cat Tunnel Client.exe" -panel -config .\client-windows.json
仅打开 http://127.0.0.1:51888/ 不会泄露配置或允许未授权操作。
1. 选择托管服务器，默认 dx.1catai.com:50001。
2. 输入接入密码或独立连接 Token，已保存时留空保持不变。
3. 选择映射数量（1-20），填写每条的 TCP/UDP、本机地址和本机服务端口。
4. 保存后自动重连，公网端口由服务端分配，可直接复制地址。

可展开“管理托管服务器”，添加后续节点。
本机服务须已启动，例如 RDP 使用 127.0.0.1:3389。
默认开启 TLS 1.3，节点凭据使用 Windows DPAPI 保护。

升级前先结束旧运行窗口，备份原 client-windows.json，
再替换程序，保留原配置和 CA 文件。不要用示例配置覆盖客户配置。
节点名称、映射名称和协议不变时，服务端优先恢复原公网端口。

此包无需 Go、Node.js 或 npm。关闭窗口会停止通用客户端。
需要 OpenSSH 和开机自动服务时，请使用 Windows SSH 独立交付包。
