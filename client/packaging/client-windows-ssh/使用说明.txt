1CatTunnel Windows SSH 中文版 0.5.2-security
====================================

用途
----
一键安装 Windows OpenSSH Server 和 1CatTunnel 自动服务。
安装完成后，即使 Windows 重启且无人登录，SSH 隧道仍会自动上线。

最快使用方法
------------
1. 双击“安装 1CatTunnel SSH.bat”。
2. Windows 弹出管理员授权时选择“是”。
3. 输入服务器接入密码，输入内容会显示为星号，不会明文回显。
4. 确认节点名称和 SSH 映射。
5. 等待监视窗口显示“公网 SSH 映射”和“连接命令”。

也可以在管理员终端运行：
  .\1cattunnel.exe install

如需强制使用包内已经校验的 Microsoft OpenSSH 组件：
  .\1cattunnel.exe install --offline-openssh

连接与实时监视
--------------
安装脚本会保持监视窗口常驻，实时显示：
- 当前软件版本和 Windows SSH 登录账户。
- 隧道服务状态、本地 SSH 地址和公网 SSH 映射。
- 可直接使用的 SSH 连接命令。
- TCP 连接建立、断开、来源、活跃连接数、持续时间和双向流量。

关闭监视窗口只会关闭画面，不会停止后台 1CatTunnel 或 OpenSSH 服务。

常用命令：
  .\1cattunnel.exe status       查看当前状态
  .\1cattunnel.exe monitor      打开实时监视器
  .\1cattunnel.exe repair       自动检查并修复
  .\1cattunnel.exe uninstall    删除隧道服务
  .\1cattunnel.exe help         查看中文帮助

程序会显示类似下面的连接命令：
  ssh -p 52743 Windows用户名@dx.1catai.com

公网端口由 1CatTunnel 服务端分配。本机 SSH 只连接 127.0.0.1:22，
默认不会直接向局域网或公网开放本机 22 端口。

重复安装或重新启动时，服务端会优先恢复同一节点、同一映射名称和协议原来的
公网端口；只有旧端口已经不可用时才会重新分配。

客户确认的免密码远程协助
--------------------------
本包中的 support-operator.pub 仅为远程协助方公钥，不包含私钥或客户密码。

开始远程协助：
1. 客户双击“开始远程协助.bat”。
2. 在 Windows 中文确认窗口中核对本机账户和密钥指纹。
3. 客户自行选择“是”后，远程协助方才可以连接。

远程协助方使用自己单独保管的私钥连接：
  ssh -i 运营方私钥路径 -p 公网端口 Windows用户名@dx.1catai.com

- 客户无需提供、更改或告诉任何人自己的 Windows 登录密码。
- 授权没有倒计时，在等待协助期间会一直有效。
- 远程 SSH 会话断开后，临时公钥会自动清除，不能再次连接。
- 客户随时可以双击“结束远程协助.bat”，立即断开会话并清除临时公钥。
- 协助密钥只能建立一个交互式 SSH 会话，已禁止端口转发、代理转发和 X11 转发。
- 原有 Windows 账户密码和客户自己的 SSH 公钥登录方式保持不变。

普通 SSH 登录凭据
-----------------
普通 SSH 登录使用现有 Windows 账户密码或客户自己的 SSH 公钥。
不要输入 1CatTunnel 服务器接入密码。Windows Hello PIN 不能代替账户密码进行 SSH 登录。

卸载说明
--------
运行下面的命令会删除 1CatTunnel 隧道服务：
  .\1cattunnel.exe uninstall

默认会保留 OpenSSH、Windows 账户、SSH 主机密钥和受保护的节点配置，
避免误删客户已有的远程访问能力。

安全说明
--------
- 当前 1cattunnel.exe 尚未使用商业 Authenticode 证书签名，Windows 可能显示“未知发布者”。分发前请核对“文件校验值-SHA256.txt”。
- 1CatTunnel 节点凭据使用 Windows DPAPI 加密保存。
- 远程协助只部署公钥，协助方私钥不在源码、安装包或客户设备中。
- 客户端服务使用 NT SERVICE\1CatTunnelClient 虚拟账户，不以 LocalSystem 身份运行。
- 配置目录仅允许客户端服务、SYSTEM 和管理员访问；备份仅允许 SYSTEM 和管理员访问。
- 客户端日志达到 8 MiB 后自动轮换，最多保留 3 份历史日志。
- 新安装的 OpenSSH 默认只监听 127.0.0.1:22。
- SSH 未认证连接前 16 个正常接收，16-32 个逐步限流，32 个为硬上限。
- SSH 登录等待最多 30 秒，单连接最多尝试认证 4 次。
- 修改 sshd_config 前会备份并执行语法检查，失败时自动恢复。
- payload 目录是 Windows 系统功能不可用时使用的离线备用组件，请勿手动修改。
- payload\openssh\LICENSE.txt 是 Microsoft OpenSSH 的原始许可证，依法保留英文原文。
